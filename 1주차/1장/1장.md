## 1장 프로그래밍

### 프로그래밍

- 프로그래밍이랑 컴퓨터에게 실행을 요구하는 일종의 커뮤니케이션이다.
- 문제해결 능력은 프로그래밍 시 해결해야 할 문제를 명확히 이해한 후 적절한 문제 해결 방안을 정의할때 요구되는 능력이다.
- 프로그래밍이란 0과 1밖에 알지 못하는 기계가 실행할 수 있을 정도로 정확하고 상세하게 요구사항을 설명하는 작업이며, 그 결과물이 바로 코드이다.

### 프로그래밍 언어

- 사람이 이해할 수 있는 자연어가 아니라 컴퓨터가 이해할 수 있는 언어, 즉 기계어로 명령을 전달해야 한다.
- 프로그래밍 언어를 사용해 프로그램을 작성한 후, 그것을 컴퓨터가 이해할 수 있는 기계어로 변환하는 일종의 번역기를 이용하는 것이다. 이 일종의 번역기를 컴파일러 혹은 인터프리터라고 한다.

> 인터프리터와 컴파일러는 사람이 작성한 프로그래밍 언어를 컴퓨터가 이해할 수 있는 기계어로 변환해 실행할 수 있도록 도와주는 프로그램입니다.

### 인터프리터

> 코드를 한 줄씩 읽고 바로 실행하는 방식입니다.  
> 소스코드 작성 → 한 줄씩 해석 → 즉시 실행

- 결과를 바로 확인 가능
- 개발 속도가 빠름
- 실행할 때마다 해석해서 상대적으로 느릴 수 있음
- 실행 중 오류가 발생하면 해당 지점에서 멈춤

예: JavaScript, Python

### 컴파일러

> 코드 전체를 한 번에 번역한 뒤 실행 파일을 만드는 방식입니다.  
> 소스코드 작성 → 전체 번역 → 실행 파일 생성 → 실행

- 실행 속도가 빠름
- 실행 전에 오류를 많이 잡아줌
- 한 번 빌드하면 다시 번역하지 않아도 실행 가능

예: C, C++

</details>

<details>
<summary><strong>현재 자바스크립트는 컴파일러 언어인가요? 인터프리터 언어인가요?</strong></summary>

> 전통적으로는 인터프리터 언어로 분류되지만, 현대 JavaScript 엔진은 인터프리터 + 컴파일러 방식을 함께 사용합니다.

### 실행 과정

1. 파싱 (코드를 읽고 문법 구조 분석)
2. 바이트코드 생성
3. 인터프리팅 실행
4. 자주 실행되는 코드는 기계어로 최적화(JIT 컴파일)

> 따라서 현재 JavaScript는 단순 인터프리터 언어가 아니라 하이브리드 실행 방식을 사용하는 언어라고 볼 수 있습니다.

### TypeScript는?

> TypeScript는 JavaScript로 변환(트랜스파일)되는 컴파일 단계를 한 번 더 거칩니다.

</details>
