## 자바스크립트 개발 환경과 실행 방법

### 자바스크립트 실횅 환경

- 브라우저는 HTML, CSS, 자바스크립트를 실행해 웹페이지를 브라우저 화면에 렌더링하는 것이 주된 목적이지만, node.js는 브라우저 외부에서 자바스크립트 실행 환경을 제공하는 것이 주된 목적이다.
- 브라우저는 Dom Api, 클라이언트 사이드 web api를 제공하지만 node.js는 Dom api, web api를 제공하지 않고 node.js 고유의 api를 지원한다.

<details>
<summary><strong>브라우저 환경과 Node.js 환경에서 같은 JS 코드가 다르게 동작하는 이유는 무엇인가요?</strong></summary>

> 브라우저 환경과 Node.js 환경에서 같은 JavaScript 코드가 다르게 동작하는 이유는 자바스크립트 문법 자체는 같지만, 코드를 실행하는 런타임 환경(Runtime) 이 다르기 때문입니다. 브라우저는 DOM, window, alert() 같은 웹 페이지 제어용 API를 제공하고, Node.js는 fs, process, http 같은 서버 및 시스템 기능을 제공하므로 동일한 코드라도 환경에 따라 실행 결과가 달라질 수 있습니다.

</details>

---

<details>
<summary><strong>JS 파일은 왜 Node.js로 실행할 수 있나요?</strong></summary>

> JS 파일은 자바스크립트 코드로 작성된 파일이며, Node.js는 Chrome V8 자바스크립트 엔진을 기반으로 자바스크립트를 브라우저 없이 실행할 수 있는 런타임 환경이기 때문에 JS 파일을 실행할 수 있습니다. 즉, 브라우저가 없어도 Node.js가 자바스크립트 코드를 해석하고 실행해 주기 때문에 터미널에서 JS 파일을 실행할 수 있습니다.

</details>

<details>

<summary><strong>브라우저에서 DOM 조작이 가능한 이유는 무엇인가요?</strong></summary>

> 브라우저에서 DOM 조작이 가능한 이유는 브라우저가 HTML 문서를 파싱하여 DOM(Document Object Model) 객체 구조로 메모리에 생성하고, 자바스크립트가 이 DOM에 접근할 수 있도록 document 와 같은 Web API 를 제공하기 때문입니다. 따라서 자바스크립트는 요소를 선택하고 내용, 스타일, 구조를 동적으로 변경할 수 있습니다.

</details>
