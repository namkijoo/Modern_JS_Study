## 자바스크립트란?

### 자바스크립트의 표준화

- 브라우저에 따라 웹페이지가 정상적으로 동작하지 않는 크로스 부라우징 이슈가 발생하기 시작했고, 결과적으로 모든 부라우저에서 정상적으로 동작하는 웹페이지를 개발하기가 무척 어려워 졌다.
- 자바스크립트이 표준화는 브라우저마다 다르게 동작하던 자바스크립트를 하나의 공통 규칙으로 정리한 과정이다.
- ES5 : json, strict mode, 배열 조작기능
- ES6 : let/const, 화살표 함수, 템플릿 리터럴, 디스트럭처링 할당, 스프레드 문법, rest 파라미터, 심벌, 프로미스, map/set, 이터러블, for -- of, 모듈 export import

### 자바스크립트 성장과 역사

- Ajax : 서버와 브라우저가 비동기 방식으로 데이터를 교환할 수 있는 통신 기능인 Ajax가 등장했다., 웹페이지가 변경할 필요가 없는 부분은 다시 렌더링하지 않고, 서버로부터 필요한 데이터만 전송받아 변경해야 하는 부분만 한정적으로 렌더링하는 방식이 가능해졌다.
- Jquery : Dom을 더욱 쉽게 제어할 수 있게 되었고 크로스 브라우징 이슈도 어느 정도 해결 되었다.
- V8 자바스크립트 엔진 : 등장으로 데스크톱 애플리케이션과 유사한 사용자 경험을 제공할 수 있는 웹 어플리케이션 프로그래밍 언어로 정착하게 되었다.
- node.js : 자바스크립트 엔진에서만 동작하던 자바스크립트를 부라우저 이외의 환경에서도 동작할 수 있도록 자바스크립트 엔진을 부라우저에서 독립시킨 자바스크립트 실행 환경이다. 비동기 i/O를 지원하며 단일리 스레드 이벤트 루프 기반으로 동작함으로써 요청 처리 성능이 좋다.

### 자바스크립트 특징

- 웹 브라우저에서 동작하는 유일한 프로그래밍 언어이다.
- 기본 문법은 C, 자바와 유사하고 셀프에서는 프로토타입 기반 상속, 스킴에서는 일급 함수의 개념을 차용했다.
- 인터프리터와 컴파일러의 장점을 결합해 비교적 처리속도가 느린 인터프리터의 단점 해결
- 프로토타입 기반의 객체지향 언어

> 배열이나 객체의 값을 쉽게 꺼내서 변수에 할당하는 문법입니다.

```javascript
const user = {
  name: "Kim",
  age: 28,
};

const name = user.name;
const age = user.age;
```

> > >

```javascript
const user = {
  name: "Kim",
  age: 28,
};

const { name, age } = user;
```

<summary><strong>자바스크립트는 프로토타입 기반의 객체지향 언어이다. 프로토타입 기반 객체지향 언어로 불리는 이유와 객체지향의 특징은?</strong></summary>

> 클래스 문법이 있어도 내부적으로는 프로토타입으로 연결되기 때문입니다.

### 객체지향의 특징

#### 1. 캡슐화

> 데이터와 기능을 하나로 묶고, 외부에서 직접 접근을 제한하는 것

```javascript
class BankAccount {
  #balance = 0;

  deposit(amount) {
    this.#balance += amount;
  }

  getBalance() {
    return this.#balance;
  }
}

const account = new BankAccount();
account.deposit(1000);

console.log(account.getBalance()); // 1000
console.log(account.balance); // undefined
```

#### 2. 상속

> 기존 객체의 특성을 물려받아 재사용하는 것

```javascript
class Animal {
  speak() {
    console.log("소리를 냅니다.");
  }
}

class Dog extends Animal {
  bark() {
    console.log("멍멍!");
  }
}

const dog = new Dog();

dog.speak();
dog.bark();
```

#### 3. 다형성

> 같은 메서드 이름이지만 객체마다 다르게 동작하는 것

```javascript
class Animal {
  speak() {
    console.log("동물 소리");
  }
}

class Dog extends Animal {
  speak() {
    console.log("멍멍");
  }
}

class Cat extends Animal {
  speak() {
    console.log("야옹");
  }
}

const animals = [new Dog(), new Cat()];
animals.forEach((animal) => animal.speak());
```

#### 4. 추상화

> 복잡한 내부 구현은 숨기고 필요한 기능만 제공하는 것

```javascript
class CoffeeMachine {
  makeCoffee() {
    this.#grindBeans();
    this.#boilWater();
    console.log("커피 완성!");
  }

  #grindBeans() {
    console.log("원두 갈기");
  }

  #boilWater() {
    console.log("물 끓이기");
  }
}

const machine = new CoffeeMachine();
machine.makeCoffee();
```

<details>
<summary><strong>프로토타입 기반이라고 하는 이유는?</strong></summary>

> JavaScript에서 객체가 다른 객체의 속성과 메서드를 물려받을 수 있게 해주는 연결 구조이기 때문입니다.

### 객체마다 함수를 만들면 비효율적

```javascript
const dog1 = {
  name: "콩이",
  bark() {
    console.log("멍멍");
  },
};

const dog2 = {
  name: "초코",
  bark() {
    console.log("멍멍");
  },
};
```

### 프로토타입으로 공유

```javascript
function Dog(name) {
  this.name = name;
}

Dog.prototype.bark = function () {
  console.log(this.name + " 멍멍!");
};

const dog1 = new Dog("콩이");
const dog2 = new Dog("초코");

dog1.bark();
dog2.bark();
```

</details>
