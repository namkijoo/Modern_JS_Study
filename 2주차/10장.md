## 10장 객체 리터럴

### 객체란?

- 자바스크리트는 객체 기반의 프로그래밍 언어이며, 자바스크립트를 구성하느넉의 모든 것이 객체이다.
- 원시 타입의 값, 즉 원시 값은 변경 불가능한 값이지만 객체 타입의 값, 즉 객체는 변경 가능합 값이다.

### 객체 리터럴에 의한 객체 생성

- 객체 생성 방법에는 객체 리터럴, Object 생성자 함수, 생성자 함수, Object.create 메서드, 클래스가 있다.
- 객체를 생성하기 위해 클래스를 먼저 정의하고 new 연산자와 함께 생성자를 호출할 필요가 없다.

```javascript
var person = {
    name : 'Lee',
    sayHello : function (){
        console.log(`Hello! My name is ${this.name}.`)
    };

console.log(typeof person);
console.log(person)
}
```

### 프로퍼티 접근

- 접근하는 방법은 마침표 표기법, 대괄효 표기법이 있다.

```javascript
var persone = {
  name: "Lee",
};

console.log(person.name);

console.log(person["name"]);
```

### ES6에서 추가된 객체 리터럴의 확장 기능

- ES6에서는 프로퍼티 값으로 변수를 사용하는 경우 변수 이름과 프로퍼티 키가 동일한 이름일 때 프로퍼티 키를 생략 할 수 있다.

```javascript
let x = 1,
  y = 2;
const obj = { x, y };

console.log(obj);
```
