## 13장스코프

### 스코프

- 변수는 자신이 선언된 위치에 의해 자신이 유효한 범위, 즉 다른 코드가 변수 자신을 참조할 수 있는 범위가 결정된다.
- 모든 식별자는 자신이 선언된 위치에 의해 다른 코드가 식별자 자신을 참조할 수 이는 유효 범위가 결정된다.

### 스코프 체인

- 변수를 찾기 위해 현재 스코프에서 바깥 스코프로 차례대로 올라가며 탐색하는 계층 구조를 말한다.

### 함수 레벨 스코프

- var키워드로 선언된 변수는 오로지 함수의 코드 블록만을 지역 스코프로 인정하며 이러한 특성을 함수 레벨 스코프라고 한다.

### 렉시컬 스코프

- 아래 예시에서는 1이 두번 찍히게 된다.

```javascript
var x = 1;

function fo0() {
  var x = 10;
  bar();
}

function bar() {
  console.loog(x);
}
```
